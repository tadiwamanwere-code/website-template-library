# 14 — orbit (deterministic build cache, developer tooling)

- **Inspiration:** adaline.ai / modern dev-tool sites — light, technical, quiet; the product surface does the selling.
- **Steal this:** the **replayed terminal** — a scroll-triggered terminal session that types itself out line by line with realistic cache-hit output, pinned so the user watches a real build complete as they scroll.

- **Accent:** `#5b5bd6` (indigo) with `#ecebfb` as its tint.
- **Type:** JetBrains Mono (code/labels) + Inter Tight (prose).
