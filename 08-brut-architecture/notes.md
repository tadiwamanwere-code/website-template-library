# 08 — Haldane Roux (architecture & urbanism)

- **Inspiration:** brutalist studio sites and technical documentation; visible grid, hairline rules, zero border-radius anywhere.
- **Steal this:** the **horizontal project track** — vertical scroll drives `x` translation through full-height project panels, each with its own internal parallax, and the pin distance is measured from real track width so it never drifts.
- **Also:** SVG site-diagram path draw (`stroke-dashoffset`), count-up statistics, clip reveals, magnetic cursor states.
- **Accent:** `#ff3c00` (signal orange) on concrete grey/paper white.
- **Type:** Archivo (condensed-ish grotesk) + IBM Plex Mono (data).
