# 05 — Locomotive Editorial

- **Inspiration:** locomotive.ca (screenshot in `_inspo-notes/locomotive-1.png`) — bold serif display type, mono capability tags ("OPS/DES/DEV"), duotone-red portrait, glitchy pixel strip, cookie-banner-style UI chrome.
- **Steal this technique:** the CSS-only duotone — `grayscale(1) contrast(1.25) brightness(.85)` + `mix-blend-mode:luminosity` on the photo, then a solid accent-colored layer with `mix-blend-mode:multiply` on top, finished with a dark scrim gradient for legibility. No image editing required, fully swappable photo.
- **Accent color:** `#8a1c1f` (deep red base tint), with `#c23a2e` as the brighter hover/highlight variant.
